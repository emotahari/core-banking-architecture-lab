## سیاست منبع

- منبع اصلی برای Factهای نسخه‌ای اولویت دارد.
- متن درس Synthesise استاد است و جای کپی‌کردن متن مرجع را نمی‌گیرد.
- هر Fact متغیر با تاریخ کنترل ثبت می‌شود.
- منابع غیررسمی می‌توانند برای مثال مفید باشند، اما مبنای نسخه یا تعریف استاندارد نیستند.
