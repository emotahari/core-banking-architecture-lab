# Day 08 Exit Ticket — Clean Code و Strategy/Factory

بدون مراجعه به درس، حداکثر در پنج دقیقه پاسخ بده.

1. تفاوت Refactoring با تغییر Rule دامینی چیست؟
2. چرا وجود `switch` به‌تنهایی Strategy را توجیه نمی‌کند؟
3. Characterization Test چه چیزی را ثابت می‌کند و چه چیزی را ثابت نمی‌کند؟
4. `boolean preferredCustomer` چه Smellی دارد و یک جایگزین معنادار چیست؟
5. Registry/Factory در این مسئله باید مالک چه تصمیمی باشد و چه منطقی نباید داخل آن قرار گیرد؟
6. یک هزینهٔ واقعی اضافه‌کردن Strategy را نام ببر.
